# EggIncognito - {LANGUAGE} Mock Server

Stateless mock server for the [Egg, Inc.](https://eggincgame.com/) API, generated by [EggIncognito](https://github.com/DavidArthurCole/EggIncognito). Do not edit by hand - regenerated on every push to main.

{PREREQS}

## Run

```sh
{RUN}
```

Listens on `http://localhost:{PORT}`.

## Configuration

| Variable | Default | Description |
|---|---|---|
| `FIXTURES_PATH` | `Fixtures` | Path to fixtures directory |
| `PORT` | `{PORT}` | HTTP listen port |

## Fixtures

Fixtures are pre-baked binary protobuf files included in `Fixtures/`. The server checks:

1. `Fixtures/eids/<EID>/<slug>.binpb` - per-player override
2. `Fixtures/default/<slug>.binpb` - fallback for all players

Set `FIXTURES_PATH` to a directory with the same layout to use custom responses.

## Regenerate

```sh
git clone https://github.com/DavidArthurCole/EggIncognito
dotnet run --project EggIncognito.CodeGen -- generate {SLUG} --bake
```
